# Тестове завдання — Backend (.NET 10 + PostgreSQL)

> Markdown-копія `Freitty_For_Candidate_Backend.pdf`. Оригінал лежить поруч.

## Контекст

У файлі `Freitty_For_Candidate.html` — три екрани кабінету клієнта логістичної платформи. Файл можна відкрити у браузері, щоб переглянути макети:

1. **Dashboard** — KPI-метрики + список останніх ордерів.
2. **Order List** — список усіх ордерів із фільтрами та статусами.
3. **Order Detail** — детальна сторінка ордера.

Верстка вже готова — дизайн вигадувати не потрібно.

## Завдання

Реалізувати backend, який живить ці три екрани даними, і підключити до нього наявний фронтенд. Верстка, стилі та поля лишаються ті самі, що в макеті.

## Вимоги до стека

- **.NET 10 / C#** — backend.
- **PostgreSQL** — база даних (обов'язково).
- ORM, структура проєкту, спосіб підключення фронту — на вибір кандидата.

## Очікування

- Дані віддає backend через API (а не захардкоджені на фронті).
- БД заповнена прикладними даними (можна взяти з макетів).
- Доменну модель і схему БД кандидат проєктує сам за макетами.
- Фільтрація, пошук і пагінація зі списку ордерів — на боці БД.
- Базова якість коду: структура, читабельність.
- README: як підняти локально.

Авторизація, pipeline/kanban-вигляд, реальні платежі та файловий сторедж для фото — не обов'язкові.
