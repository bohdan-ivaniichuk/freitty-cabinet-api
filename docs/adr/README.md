# Architecture decision records

One file per decision that shapes the code and is worth defending in review, named
`NNNN-<decision>.md` (`0001-fastendpoints-over-controllers.md`). Not every choice needs one — only
those where a reasonable engineer could have chosen differently.

Template:

```markdown
# NNNN — <Decision>

- Status: accepted | superseded by NNNN
- Date: YYYY-MM-DD

## Context
The problem and the forces at play.

## Decision
What we do.

## Alternatives
- <option> — why not.

## Consequences
What gets easier, what gets harder, what we accept.
```
